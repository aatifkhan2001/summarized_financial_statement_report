## 📌 Project Overview

This project focuses on analyzing the financial performance of National Investment Company Kuwait using publicly available financial statement data from 2022 to 2025.

The dataset was extracted from published financial reports and contains summarized financial statement information, including income statement and balance sheet data. The objective of this project was to transform raw financial data into an interactive dashboard that provides insights into profitability, financial position, and historical performance trends.

---

## 📂 Data Source

The financial data used in this project was obtained from publicly available financial statements published by National Investment Company Kuwait.

The dataset includes summarized financial information such as:

- Revenue and income components
- Operating expenses
- Net profit
- Assets
- Liabilities
- Equity
- Financial statement categories
- Other reported financial metrics

The dataset covers the period from **2022 to 2025**, allowing for multi-year financial trend analysis.

---

## 🛠️ Data Preparation & Transformation

The financial statement data was cleaned, structured, and prepared for analytical reporting.

Key preparation steps included:

- Extracting financial statement information from published reports
- Organizing financial accounts into structured categories
- Transforming financial statements into an analytical format
- Creating calculations for financial performance metrics
- Preparing data for interactive visualization and reporting

---

## 📊 Dashboard Features

The dashboard provides an overview of National Investment Company Kuwait's financial performance through interactive visualizations and key financial metrics.

Users can analyze:

- Revenue and income trends
- Profitability performance
- Expense movements
- Asset and liability changes
- Equity composition
- Year-over-year financial performance

Interactive filters allow users to explore financial results across different years and reporting periods.
